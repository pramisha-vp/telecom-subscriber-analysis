# Telecom Subscriber Analysis & Forecasting

## 📌 Project Overview
This is my Post-Graduate (PG) data analytics project focused on analyzing telecom industry data. The goal of this project is to clean historical subscriber datasets, analyze consumer trends, and build statistical time-series forecasting models to predict subscriber growth.

## 🛠️ Tech Stack & Tools Used
* **Data Cleaning & Analysis**: R Programming
* **Statistical Modeling**: Time-Series Forecasting (ARIMA Model,Holt Model,ETS Model)
* **Data Storage**: Excel 

## 📈 Key Learnings & Problem Solving
* Structured and cleaned messy real-world telecom datasets by handling missing values and data anomalies.
* Learned the importance of data stationarity in time-series forecasting.
* Identified initial modeling errors and refined the statistical approach to improve prediction accuracy.
* Generated statistical plots directly in R Programming to visualize model residuals, trend components, and final forecast projections.
